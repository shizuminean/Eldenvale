ELDENVALE RPG
PC     : pip install pygame ; python main.py
Kontrol: WASD/Panah jalan | Z/Spasi/Enter bicara & pilih | I/Esc buka Tas | P ramuan cepat | F2 setelan | F5 simpan | F9 muat
HP     : joystick kiri, tombol A (bicara/OK) dan B (ramuan), tombol TAS/SIMPAN/MUAT di kanan atas
Peta   : Desa Eldenvale -> gerbang selatan -> Hutan Berburu (monster terlihat, mengejar jika kamu dekat)
APK    : push ke GitHub (branch main) -> tab Actions -> Build APK
